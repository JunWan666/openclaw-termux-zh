# OpenClaw Android 中文版 v3.0.0

v3.0.0 是一次运行环境和首次使用流程的重大重构。ARM64 完整版 APK 内置 Ubuntu、Node.js、npm 和 OpenClaw，用户安装后无需 Termux，也无需在首次初始化时下载运行环境。

Android 版本信息：

- `versionName`: `3.0.0`
- 基础构建号：`81`；Flutter 分 ABI 后 ARM64 APK 的实际 `versionCode` 为 `2081`
- 最低系统：Android 10
- 发布架构：ARM64 (`arm64-v8a`)

## 内置运行环境

- Ubuntu `24.04.3`
- Node.js `24.18.1`
- npm `11.16.0`
- OpenClaw `2026.3.23`

## 主要变化

### 本地初始化

- 首次初始化从 APK 本地部署完整运行环境。
- 初始化不下载 Ubuntu、Node.js 或 OpenClaw 2026.3.23。
- 初始化不执行完整 `npm install`。
- 新增设备兼容、存储空间、归档 SHA-256 和关键运行文件验证。
- 解压失败或应用中断时通过事务目录恢复，不直接破坏现有 RootFS。

### 初始化界面

- 重构欢迎页、部署页、完成页和阶段轨道。
- 使用环形平滑进度、阶段状态和实时部署动态，避免长时间只显示固定百分比。
- 日志去重、限制数量，并自动脱敏 API Key 和 Token。
- 初始化成功后等待用户点击“进入 OpenClaw”。

### 默认 AI 服务

- 新增 `7749API（ywd 公益）` 提供商。
- 初始化后自动写入可用的默认提供商与模型配置。
- 支持在线拉取模型列表并切换其他模型。
- 隐私敏感场景仍建议用户换成自己的提供商和 API Key。

### OpenClaw 版本管理

- `2026.7.1` 标记为“最新 · 推荐”。
- `2026.3.23` 直接从 APK 恢复，不下载、不运行 npm install。
- 升级和降级前创建保护事务，保留配置、Agents、Workspace、Memory 和技能。
- 下载过的版本安装包继续保留。
- 离开某个已安装版本时保存完整版本快照；再次切回时直接交换快照，跳过下载和 npm install。
- 最多保留两个非当前版本快照，控制存储占用。

### npm 缓存

- 持久 npm 缓存移动到 RootFS 外部应用目录。
- 默认容量从 512 MB 提升到 1 GB。
- 设置页允许关闭、选择容量或设为不限制。
- 超过限制时按较旧文件渐进淘汰，不再清空整个缓存。

### Gateway 与 Web 控制台

- 优化 Gateway 冷启动、残留进程清理和配置准备顺序。
- 优化 Web 控制台首次连接速度和 Token URL 获取。
- 调整 WebView 页面缩放提示的位置与展示方式，避免遮挡输入框和发送按钮。

## 升级说明

1. 3.0.0 开始使用新的长期正式签名，不能直接覆盖安装任何 2.x 签名包。
2. 旧用户必须先在旧版“备份中心”导出重要配置和工作区，再卸载旧 App；卸载会清除应用私有目录。
3. 安装 3.0.0 并完成本地初始化后，再通过备份中心导入旧数据。
4. v2.0.3 Release 已撤回，不建议继续传播旧安装文件。
5. 版本切换完成后的 `openclaw doctor` 配置检查仍可能需要额外时间。
