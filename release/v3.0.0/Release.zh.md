# OpenClaw Android 中文版 v3.0.0

v3.0.0 是内置运行环境正式版。ARM64 APK 已包含 Ubuntu 24.04.3、Node.js 24.18.1、npm 11.16.0 和 OpenClaw 2026.3.23，首次初始化不再下载这些核心组件，也不运行完整 npm install。

版本信息：`versionName 3.0.0`，基础构建号 `81`，ARM64 分包实际 `versionCode 2081`。

## 重点更新

- 全新欢迎、初始化进度、部署动态和完成页面。
- 默认配置 `7749API（ywd 公益）`，支持拉取和切换模型。
- OpenClaw 2026.7.1 标记为“最新 · 推荐”。
- 2026.3.23 可从 APK 本地快速恢复。
- 版本切换使用保护事务并保存完整版本快照，再次切回可跳过下载和 npm install。
- npm 持久缓存默认 1 GB，超限后渐进淘汰旧文件。
- 优化 Gateway 冷启动、Web 控制台连接和页面提示。

## 升级提醒

- v2.0.3 Release 已因问题撤回，请不要继续使用或传播旧安装文件。
- 3.0.0 启用新的长期正式签名，不能覆盖安装 2.x：请先在旧版备份中心导出数据，再卸载旧 App、安装 3.0.0，最后导入备份。
- 卸载旧 App 会清除其私有目录，没有导出的配置和工作区无法自动迁移。
- 默认公益 API 服务由第三方维护；隐私敏感场景请配置自己的提供商。
