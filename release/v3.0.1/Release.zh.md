# OpenClaw Android 中文版 v3.0.1

v3.0.1 是基于 v3.0.0 内置运行环境版本的正式维护更新，重点调整 AI 提供商首次配置、消息平台插件安装流程，并修复本地模型运行时下载。

版本信息：`versionName 3.0.1`，基础构建号 `82`，ARM64 APK 实际 `versionCode 2082`。

## 重点更新

- 首次初始化默认引导配置 DeepSeek 官方 API，不再内置可直接使用的第三方 API Key。
- `7749API（ywd 公益）` 更新为 `open7749` 新端点和模型，并自动迁移旧配置与用户已有 API Key。
- QQ 机器人和微信插件改为手动检测和显式安装；QQ 新增独立终端安装页。
- 微信安装器根据真实进程退出码返回成功或失败。
- 修复 llama.cpp 最新稳定 Release 缺少 Ubuntu 二进制包时的运行时下载问题。
- 本地模型页面优先展示运行时安装入口和安装日志。

## 升级说明

- v3.0.0 用户可直接覆盖安装 v3.0.1，两个版本使用相同的长期正式签名。
- 2.x 用户需要先导出备份，再卸载旧版、安装 v3.0.1 并导入备份。
